# Belusys-test-FE

ReactJS + TypeScript + Ant Design frontend for the Student Classroom Management System.

## Requirements

- Node.js 22.18.0 or newer
- npm 11 or newer

## Setup

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

Set `VITE_API_URL` in `.env` to the backend base URL.

## Commands

```powershell
npm run dev
npm run build
npm run lint
npm run preview
```
